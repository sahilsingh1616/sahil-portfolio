SAHIL SINGH — SEO & DIGITAL MARKETING PORTFOLIO
================================================

FILES
- index.html: all page content and sections
- style.css: dark professional styling and responsive layout
- script.js: mobile menu and current year
- assets/profile-placeholder.svg: temporary profile image placeholder

STEP 1 — PERSONALISE BEFORE PUBLISHING
1. Open index.html in VS Code or a text editor.
2. Search for "your.email@example.com" and replace it with your real email.
3. Replace https://www.linkedin.com/ with your own LinkedIn profile URL.
4. The homepage profile now uses Sahil Singh and 4+ years of experience, based on your confirmation. Review all profile claims, platform/tool lists and hourly rate before publishing; edit anything that is not accurate for you.
5. Add real project case studies, screenshots and outcomes only where you have permission and evidence.
6. Replace assets/profile-placeholder.svg with your own photo. Rename your photo to profile.jpg, put it in assets/, then change the image path in index.html to assets/profile.jpg.
7. Update the page title and description if you want.

STEP 2 — PREVIEW ON YOUR COMPUTER
- Extract the ZIP.
- Open the seo-portfolio folder.
- Double-click index.html to preview in your browser.
- For easier editing, install Visual Studio Code (optional).

STEP 3 — PUBLISH FREE WITH GITHUB PAGES
1. Create or sign in to a free account at https://github.com/
2. Create a new public repository named: sahil-portfolio
3. Upload index.html, style.css, script.js, README.txt and the assets folder.
   Important: index.html must be in the repository root, not inside another nested folder.
4. Open repository Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. Your site URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/sahil-portfolio/
   (The exact URL depends on your GitHub username.)

NO PAID DOMAIN REQUIRED
GitHub Pages provides a free github.io subdomain for a public repository. You do not need to buy a .com or .in domain for this setup.

BEFORE SHARING
- Test on mobile and desktop.
- Check your email, LinkedIn and photo.
- Remove all placeholder details.
- Do not publish private client data or confidential work.
